# D radix buckets with separate key and node arrays (unselected)

This isolated candidate replaces each radix bucket's `Vec<(u64,u32)>` with a pair of synchronized `Vec<u64>` keys and `Vec<u32>` node IDs. The minimum scan reads contiguous keys rather than 16-byte tuple entries. Every push, pop, clear, and redistribution updates both vectors; the arrays' lengths and index correspondence are invariants. The graph algorithm and packed adjacency trial are unchanged. The tradeoff is more vector operations, allocation metadata and potentially separate memory accesses. No graph input or answers are precomputed.

The baseline is the currently official-testing packed32 source SHA-256 `793d13729fe4dabe2a1ed272fef78e19567456676ed8df52c075bc4ac33ebd05`. Candidate SHA-256 `d0a46b1df5a15e21814f81610d5590efdc2604c0877dff1d6b8a02e2620a081c`. No independent review, x86 hardware test, official score, or worst-case cgroup measurement has been performed.

On an overflow-checked/debug-assertion native ARM build, the candidate passed 16,000 random directed graph queries against an independent Dijkstra oracle, 36,864 all-pairs queries for all 4,096 three-node directed graphs, and compact/fallback boundaries at 2^21 and 2^21+1 nodes including weights 0, 2046, 2047 and UINT32_MAX. `property-tail.rs` appends an independent BTreeMap/HashSet monotone-heap model to the exact candidate; 1,000,000 mixed insert/pop operations plus complete drains and 40 reset cycles passed with debug assertions and overflow checks. These tests do not prove all execution paths, allocator behavior or official performance.

Performance is pending; any sample measurement is subject to shared-host noise and may not predict full-scale or target performance. This is an unselected experiment and no Mac Docker was used.

Two randomized 15-pair native ARM seed-1 **sample** batches, including a warmup pair each, produced the expected hash in all 64 executions. Candidate versus baseline median wall seconds were `0.025194 / 0.022616` and `0.022807 / 0.020656` (about 11.4% and 10.4% slower). Median CPU seconds were `0.123322 / 0.109289` and `0.116360 / 0.105688`. Maximum native process RSS was 56,197,120 / 55,590,912 bytes and 56,524,800 / 55,754,752 bytes. These short sample runs on a shared host are not full-size, x86, official, or cgroup evidence; both batches provide no reason to select this candidate. Source identities, flags and observations are in `sample-a.json` and `sample-b.json`. No Mac Docker was used.
