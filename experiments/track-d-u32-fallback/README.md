# Adaptive u32 search with exact u64 fallback (experimental, not selected)

`candidate.rs` first runs bidirectional Dijkstra with two `u32` distance fields per vertex, using complemented zero as unreached. It rejects any relaxation with distance at least `u32::MAX`; if it finds a result strictly below that limit it returns the result, otherwise it lazily allocates the original `u64` search state and reruns the query exactly. For nonnegative weights, any path shorter than the cutoff has every prefix and suffix shorter than the cutoff, so the first search cannot discard a path that beats an accepted result. Exact cutoff, above-cutoff and unreachable answers use the unrestricted fallback. This prototype has not received independent review or target-machine measurement.

In five randomized native Mac ARM full seed-1 pairs after warmup, every output matched the published SHA-256. Candidate median wall was 0.923706 s versus 0.954333 s baseline, median CPU 2.260292 versus 2.426268 s, maximum process RSS 425,017,344 versus 533,774,336 bytes. Other agents were active, ranges overlapped substantially, and process RSS is not official warmed-cgroup memory. Under the speed-first priority the small/noisy difference does not justify selection.

The candidate also passed 80 randomized directed graphs / 16,000 oracle queries and 4,096 exhaustive three-node graphs / 36,864 all-pairs queries against Floyd–Warshall, plus `python3 thresholds.py /path/to/candidate` covering 2^32−2, 2^32−1, 2^32, zero, unreachable and self cases. Those checks do not prove every legal case. Before promotion, independently review sentinel/fallback/cleanup, exercise large-weight and epoch reuse cases, measure target x86 wall and warmed cgroup memory, and compute source S.

For paired comparison, copy `candidate.rs` to `meeting.rs` in a temporary directory next to `baseline.rs` and `compare.py`, then run `python3 compare.py --data /path/to/full-d --build-dir /tmp/d-u32-build --report /tmp/d-u32.json --runs 5`; it compiles equal release flags and verifies every full output hash. No Docker was used.
