# B token length, match and probe diagnostic

`baseline.rs` is the exact selected source SHA-256 `7d371fe84ce9f0fd9d3c7e6fdf02b6b37e0f1440319c654161b990cf27bb8bf3`. `make-profile.py` constructs `profile.rs` (SHA-256 `d7bc4dec39197e060e4c033329efd17b1d0b89368f930dc2bed1494c2dac011e`) by counting token lengths and query-dictionary hits/misses, then independently repeating short-key probing and asserting it returns the same ID. The instrumentation changes cost and is **not a performance benchmark**. It does not alter the query result.

Two full public seed-1 native ARM runs used `rustc --edition=2021 -O -C lto=fat -C codegen-units=1 -C panic=abort`, then `SD_DATA=/tmp/speed-b-full SD_OUT=<private temporary output> <profile-binary>`. Both outputs matched published SHA-256 `f86973c210228141bcb6f1f1b10188ad2a9b65f71e7cd7cf4590b38de4e80927`. The first overlapped a brief unrelated compile; the repeat was exclusive. Counts are deterministic and `summarize.py` asserts both histograms match, excludes the initial 512 KiB sample scan, and checks the eight chunk intervals exactly cover the 253,827,587-byte corpus. No time or resource inference follows. `diagnostic.log`, `diagnostic-repeat.log`, and `summary.json` preserve the evidence.

Of 36,276,657 corpus tokens, 28,716,697 (79.16%) matched an interned query term. Tokens of lengths 1–3 were 10,854,229 (29.92%); 10,752,901 (99.07%) of those matched. Lengths 1–4 were 14,511,893 (40.00%) with 97.47% matches. Lengths 1–8 were 28,971,614 (79.86%) with 83.27% matches. Among the 24,125,591 matched short tokens, 95.96% stopped at the first short-table slot; among 4,846,023 missed short tokens, 62.26% stopped at the first slot. Probe histogram bin 15 combines 15 or more probes, so the calculated average probes would be a lower bound.

These are observations for one public seed, not guarantees for hidden data, not a measurement of CPU cost, and not evidence that a lookup optimization wins on the official x86 machine. No dataset, credentials or executable is included. No Mac Docker was run.
