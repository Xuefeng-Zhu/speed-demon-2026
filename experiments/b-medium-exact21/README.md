# Guarded exact medium-token dictionary (unselected)

This isolated candidate builds an additional open-addressed table for query terms of 9–16 alphanumeric bytes, storing IDs and verifying both original 64-bit key words on hits. The term set comes only from queries. Lookup of terms beyond 16 bytes uses the original exact table; the existing short path, query semantics and memory caps are unchanged. If an insertion needs more than 32 occupied probes or a cyclic occupied run exceeds 64 slots, the medium table is discarded and every 9–16 byte lookup falls back to the original exact table. This limits the added table's collision scans; it is not a universal bound on the original table. Baseline SHA-256 is `7d371fe84ce9f0fd9d3c7e6fdf02b6b37e0f1440319c654161b990cf27bb8bf3`; final guarded candidate SHA-256 is `f58972f701711d06fc5c24da546af8c74c66b81805cf73ba8fea200ac9d475bf`.

Two exclusive randomized 11-pair full-seed native ARM screens after warmup found candidate/baseline median wall 0.236584/0.235848 s and 0.232696/0.234521 s; CPU 1.520543/1.538498 s and 1.518101/1.527772 s. All 48 measured and warmup outputs matched the published full hash. An earlier unguarded draft's 0.237804/0.244354 s screen is not a measurement of the final candidate. Results are short, shared-Mac scalar-path observations, not x86 or cgroup data; they do not establish a stable wall win. No official practice is recommended based on them.

The guarded source passed 40 mixed official-reference corpora, six >1 MiB documents, and distributed-top-ten/duplicate/overlap checks. `python3 experiments/b-medium-exact21/run-property.py` checks 9,600 generated keys across lengths 1–32, uppercase/lowercase, offsets and end-of-buffer/direct reads with overflow checks; a separate forced-constant-medium-hash build exercises table fallback and compares the same exact expected lookups. This work has no independent review, x86 guard-page/AVX2 test, target timing, or cgroup evidence. No Docker ran on the Mac. To reproduce screens, compile both sources with `rustc --edition=2021 -C opt-level=3 -C lto=fat -C codegen-units=1 -C panic=abort` and run `experiments/b-rust-lengthhash/compare.py` against separately generated full data.
