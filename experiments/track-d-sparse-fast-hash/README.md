# Custom sparse table, one-multiply hash (experimental, not selected)

This variant of `../track-d-sparse-custom/` uses one seeded multiplication and xor-fold instead of the two-multiply mixer. Full hashes, 16,000 random queries, 36,864 exhaustive three-node queries, max-size max-weight chain, 6,000 repeated/unreachable queries and the forced-collision/growth/generation-wrap table test passed. Nine shared ARM native pairs (`report.json`) measured median 0.34213 vs 0.27806 s baseline, CPU 2.20378 vs 1.88280 s, max native RSS 346,292,224 vs 534,462,464 B. The lower RSS does not offset slower wall under the user's speed-first direction. Hash distribution and worst-case runtime have not received independent review; this is not x86 or official cgroup evidence. No Mac Docker was used.
