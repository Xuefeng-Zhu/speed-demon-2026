# Packed D inline-two row experiment (unselected)

`baseline.rs` is the exact selected packed adjacency (`793d13729fe4dabe2a1ed272fef78e19567456676ed8df52c075bc4ac33ebd05`). `candidate.rs` / `meeting.rs` (`0f88cf20669200c3974cad7da29cea7fe73a4e35d7930c3238a671bae677078d`) add a runtime-built 16-byte row per node containing the original start/end offsets and the first two packed 32-bit edges when the row has at most two edges. These rows replace the original offsets array. Larger rows use the unchanged compact array. Wide values retain the exact global edge-position side array; inputs with more than 2^21 nodes retain the original u64 adjacency path. The compact array is still fully allocated and populated, so the inline rows duplicate their short-row edges. There are no precomputed graph data.

The optimized debug/overflow-checked candidate passed `track-d-balanced-frontier/oracle.py` (80 random directed graphs, 16,000 independent queries), `track-d-balanced-frontier/exhaustive.py` (4,096 graphs, 36,864 all-pairs queries), `track-d-packed32-adj/boundaries.py` (2^21 and 2^21+1 nodes, weights through u32::MAX) and `track-d-balanced-frontier/extremes.py` (full-size max-weight chain and 6,000 repeated/unreachable queries). Correctness checks do not establish every graph or concurrent build schedule; it has not been independently reviewed.

One randomized 15-pair warmed native macOS ARM sample comparison yielded median wall 0.024111 s candidate versus 0.020195 s baseline, median CPU 0.122846 versus 0.104255 s, and peak process RSS 60,555,264 versus 54,984,704 bytes. All 32 outputs (15 pairs plus warmups) matched published sample SHA-256 `a4c76ed030bc7e365db33191f6cf74708fba7f25eb48d64c8c4279f2e57046a0`; see `sample-arm.json` for individual measurements and compiler flags. Short sample timing on a shared host is a preliminary negative screen and does not predict full-size, x86, official or cgroup performance. The candidate remains unselected. No Mac Docker was used.

Reproduce against an independently generated sample with `python3 experiments/track-d-packed-inline2/compare.py --data /path/to/sample --build-dir /tmp/sd-inline2-build --report /tmp/sd-inline2-report.json --runs 15 --expected a4c76ed030bc7e365db33191f6cf74708fba7f25eb48d64c8c4279f2e57046a0`.
