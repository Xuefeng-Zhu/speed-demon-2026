# Track C libc delimiter scan

Experimental `main.rs` (SHA-256 `6ab1c5f7bd80b618ceeb81032ac3c8fef26a7ba7bf034665e4ac4430a3130210`) replaces field delimiter iteration in the selected e6e72ac C implementation (source SHA-256 `5c9fcd972b561673c0b15c0ed24ae7dd411e09ba28285e7ea05700aacf892bd4`) with libc `memchr`, checking for null before computing the offset. Exact field semantics, quote handling, storage and aggregation are otherwise unchanged. The system libc supplies `memchr`; no crate or downloaded dependency is added. The candidate is not selected.

Eight randomized full seed-1 pairs after warmup on a shared macOS ARM host all matched the published hash. Median wall was 0.161795 s variant versus 0.172321 s baseline; median CPU was 0.893325 vs 0.948538 s; peak process RSS ~226 MB each. These noisy native measurements are not official x86 or cgroup results. The candidate matched the official reference across 24 independent CSV corpora at each of five worker counts (120 checks), covering quoted, escaped, long, BOM, CRLF and multiline fields. Target-machine benchmarking and independent review remain needed.

Compile both versions with equivalent release flags, then use `python3 experiments/c-memchr/compare.py --baseline /path/to/base --variant /path/to/variant --data /path/to/full-c --report /tmp/c-memchr.json`. It checks every published full hash and measures wait4 process RSS, not cgroup memory. To repeat the independent reference checks, run `python3 experiments/c-rust-independent.py --source experiments/c-memchr/main.rs --seeds 24`.

A second isolated `fxbytes.rs` variant replaced byte-by-byte hash word assembly with zero-padded little-endian 64-bit assembly. Eight shared-ARM pairs measured 0.167927 s versus 0.179364 s baseline, with CPU medians 0.885760 vs 0.898780 s; all full hashes matched, but the small CPU difference and overlapping times do not establish a target gain. Combining that change with `memchr` in `combined.rs` measured 0.190948 s versus 0.170742 s for `memchr` alone, CPU 0.918915 vs 0.866270 s, across eight paired full-hash runs under contention. Both remain unselected; raw reports are retained.
