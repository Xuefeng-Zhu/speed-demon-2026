# Degree-two links fused into CSR scatter (experimental, not selected)

Based on safe joint in-place shortcuts, this candidate reads query endpoints first, then forms the link table during the existing forward and backward CSR scatter loops. Each worker owns the same node block in `first` and `links`; query pins and vertices with more than two distinct undirected neighbors use an invalid bit. The second directional pass finalizes incomplete or invalid links. The later rewrite still uses immutable links and disjoint mutable CSR slices. There is no new unsafe code. Baseline is positioned-read D at b4f634b.

A feasibility review found the worker/block and presence-bit approach sound, but did not prove full graph equivalence independently. Debug/overflow-checked candidate passed 16,000 random graph queries, 36,864 exhaustive three-node queries, 376 directed chain/cycle fixtures, the maximum-size maximum-weight chain and 6,000 repeated/unreachable queries. All full-seed hashes matched. Nine shared ARM native pairs (`report.json`) measured median 0.37544 s vs 0.32151 s baseline, CPU 1.94958 vs 1.82996 s, and max native RSS 555,384,832 vs 534,347,776 B. This slower screen is not target x86 or official cgroup evidence. The candidate is unselected; no Mac Docker was used.
