# Compact per-ID short-key cache (unselected)

`baseline.rs` is exact selected B source SHA-256 `7d371fe84ce9f0fd9d3c7e6fdf02b6b37e0f1440319c654161b990cf27bb8bf3`; `candidate.rs` SHA-256 `a68cac5483f246f26f2bec52a81989c4361a5e61059d1568a2e7a226f8b83f47`. The candidate copies the first 64-bit word of each query-derived key to a compact global-ID-indexed array if there are at most 262,144 keys (at most 2 MiB requested element payload); larger query dictionaries use the exact existing 32-byte-stride key lookup. Slots, hash/probe order, complete short-key equality, longer-token lookup, phrase and Boolean processing remain unchanged. No cached corpus inputs or answers are used. Array allocator charges and whole-process/cgroup peak are not bounded by the 2 MiB element payload alone.

An optimized, overflow-checked exact-source property driver tested no-key, 1-, 255-, 4,096-, 262,144- and 262,145-key plans, present/missing and mixed-case exact matches, legal 1–32-byte fallback and constant-short-hash collisions on small tables. The candidate passed 90 independent mixed-reference corpora, including empty docs and no short-query terms. Tests ran on native ARM, not actual x86 AVX2 or protected pages; they do not prove all valid inputs.

An 11-pair randomized full seed-1 native ARM screen after warmups measured baseline/candidate median wall `0.238926/0.242586 s` and CPU `1.527636/1.589538 s`, with all 24 hashes matching the published output. This is one shared-host scalar-classifier screen, not an x86 score, PGO result or cgroup measurement; it gave no evidence of a substantial win. The candidate remains unselected. Raw results are in `arm-screen.json`.

Run `python3 experiments/b-compact-idkey32/property.py` for exact-source boundary and forced-collision properties. For a local screen, compile both sources with identical `rustc --edition=2021 -O -C lto=fat -C codegen-units=1 -C panic=abort`, run `python3 experiments/b-short-lookup/independent-review.py <candidate>`, and run `python3 experiments/b-rust-lengthhash/compare.py --baseline <baseline> --candidate <candidate> --data <full-seed-dir> --runs 11 --report <report>`. No dataset, credentials or binaries are included. No Docker was run on the Mac.
