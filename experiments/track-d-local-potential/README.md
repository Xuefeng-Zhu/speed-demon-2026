# Local-edge-potential bidirectional A* (experimental, not selected)

This candidate computes minimum outgoing and incoming edge weights per vertex at runtime; absent edges and the relevant query endpoint use zero. These are admissible consistent local bounds. Their difference yields a feasible doubled potential for bidirectional A*, with transformed heap keys and original distances retained for relaxations and meeting bounds. Baseline is positioned-read D source `ac9674a11b90244c63a518ee94eb7a9547353540ff564672aaa128ac4851a2ea`. An independent mathematical consistency review covered zero-weight edges, loops, parallel edges, absent edges and i64 arithmetic bounds, but this is not a full implementation proof.
