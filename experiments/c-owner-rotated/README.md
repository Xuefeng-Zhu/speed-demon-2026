# C compact-owner unseeded prehash — high-risk, unselected

This experimental variant carries a 64-bit Fx name hash in each 16-byte owner event and uses an unseeded rotated identity map to avoid rehashing names. Baseline is the separately proposed 8-byte compact owner, not the selected source. Exact name bytes are still compared; size and group overflow use the same pre-output fallback as compact owner. All 120 mixed references, 20 long/sentinel/forced-fallback cases, 20 group boundaries, 12 collision/growth checks and 357 CRLF boundary checks passed, but no actual >4 GiB mapping or x86 target execution was done.

The deterministic map is **not recommended**. Independent review constructed 16,384 synthetic distinct prehashes in one owner with matching bucket/control bits, producing around 158 ms insertion time versus 0.54 ms salted; legal-name Fx preimages for that particular synthetic family were not established. A separate search produced 512 distinct uppercase-letter names valid under the documented character grammar, routing to the same owner and colliding in those bits: one native insertion-only trial was 164 µs versus 46 µs original. These names were not shown to occur in official generated seeds. Both cases preserve output but demonstrate plausible pathological work; name length/distribution are not bounded by the planning guidance. Full-equal-hash inputs also route to one owner. Do not promote based on speed alone.

Two ARM pairs batches against compact owner gave candidate/baseline median wall 0.07844/0.08536 s and 0.08761/0.09580 s; CPU 0.44120/0.50486 and 0.44544/0.51255 s. A separate batch versus selected gave 0.08946/0.11894 s wall and 0.43783/0.67794 s CPU. All output hashes passed, but native peak RSS was ~284 MB versus ~253 MB compact and ~226 MB selected; these are shared Mac results, not target scores. `arm-*.json` preserve samples. The separate `c-owner-salted` experiment mitigates distinct-hash bucket clustering and caps equal-hash chains, but was tied with compact owner in its ARM screen. No Mac Docker was used.
