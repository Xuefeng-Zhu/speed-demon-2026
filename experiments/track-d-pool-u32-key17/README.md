# Narrow-key pool layout (unselected)

`baseline.rs` is the selected batch16 search (SHA-256 `7fd333be25133a78264cb4b84441de46d4c8bcbfd73914af23761f23d8c47f17`); isolated `candidate.rs` is SHA-256 `42d95c47a487779929884c04bec2fbaa11952aa85240c93b688c869b568dcb31`. It stores the narrow radix queue's key as `u32` rather than `u64`, retaining the graph, all searches, fixed pool cap, cleanup and exact wide fallback. The narrow `reach` guard admits only keys strictly less than `u32::MAX`; `push` is private to this search and a debug assertion checks the invariant. Values are widened before radix comparisons and return. On the tested target Rust layout this changes a pool node from 16 to 12 bytes: at capacity 65,536 and 12 workers with two heaps, requested element payload decreases from 24 MiB to 18 MiB. This is not a full parent-cgroup bound and excludes allocation/runtime charges.

`python3 experiments/track-d-pool-u32-key17/verify.py` passed optimized debug-assertion/overflow builds with caps 0/1/2/65,536: 16,000 random-graph oracle queries and 36,864 exhaustive three-node answers per cap, cutoff and unreachable tests, 2^21/2^21+1 node and weight boundaries, maximum-weight chain and 6,000 repeated/unreachable queries. The cap-zero and cap-one builds exercised wide fallback. These finite checks do not establish all-input correctness, cgroup limits or target performance.

A native shared-Mac ARM sample screen generated with the official seed-1 sample generator ran one warmup and 21 randomized pairs; all 44 output hashes matched `a4c76ed030bc7e365db33191f6cf74708fba7f25eb48d64c8c4279f2e57046a0`. Median wall was 0.019676 s candidate versus 0.018782 s baseline (candidate 4.8% slower); median CPU 0.101007 versus 0.098292 s (2.8% higher); maximum process RSS 43,139,072 versus 44,843,008 bytes. See `sample-arm.json` for raw measurements and flags. Short sample timing is noisy and does not establish x86 or official performance. No full-data or cgroup test was available; this preliminary result does not justify promotion or priority x86 testing. No Docker was run on the Mac.
