# Independent global-query review

Reviewed `shared.rs` SHA-256 `58ea98f48a322c3af1837a1dd1a19767250232e4c3f690e298c7e9ac95c83dfe` against selected baseline `322cc95ee08cf6d4abc5e1b52240753f66c7eaf89ab669cb6d72b0a8487dc458`. No defect found under the official dense ascending document-ID grammar.

Each chunk's local postings become `first + local_id`; this is important because chunk starts need not align to 64-document bitmap words. Sparse AND accumulates matching postings across every chunk into one cleared temporary bitmap and swaps only after the full term. AND/OR/NOT are applied in the original order. Bitmap bits are initially zero and only actual document IDs are set, so NOT cannot create tail bits outside the corpus. Phrase counts and sums add each chunk's `first` offset; first-ten IDs are taken from chunks in input order, including empty chunks. Contiguous query partitions are joined in order, preserving duplicate queries and output order.

`OnceLock` publishes each immutable global bitmap, and atomic `fetch_update` reserves its payload before allocation. At most 64 MiB of bitmap payload can be accepted in total; failed reservations cache `None`, and query evaluation falls back to exact postings. Other cache metadata and worker scratch memory are not included in the payload cap. Relaxed ordering on the counter is sufficient for quota accounting because publication is provided by `OnceLock`. This review and finite stress tests are not a race-detector proof. Potential practical risks are shared-cache contention, query-order load imbalance and loss of chunk-local cache locality; x86 timing and official cgroup memory remain unmeasured.

The independent reference suite covers 323,200 query comparisons across document counts 0/1/2/7/63/64/65/127/128/129, workers 1/2/3/7/12/32, and zero/eight-byte cache quotas. An independent 16-thread test verified exactly seven published bitmaps out of 256 under a quota of seven bitmaps plus 13 bytes, global offsets crossing bit 64, consistent values and zero-cap fallback. The separate 32-thread suite covers 48 runs at zero, eight-byte, five-bitmap and all-bitmap quotas.
