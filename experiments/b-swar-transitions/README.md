# B eight-byte transition scanner (experimental)

Relative to the selected 4f2d688 Rust B, `transitions.rs` identifies each document's text extent and classifies eight ASCII bytes per word. Its per-byte subtraction is protected from cross-lane borrows by setting the high bit first; non-ASCII bytes are separators. It then visits only word-level transitions into and out of tokens, preserving the same 32-byte keys, dictionary, bounded phrase summaries and bitmap cap. This is experimental and not selected. A simpler per-token SWAR screen was slower; see `experiments/b-swar-token/`.

All sixteen full seed-1 outputs (including warmups) matched the published hash. On seven randomized shared-Mac ARM full-data pairs, median wall was 0.301836 s candidate versus 0.311359 s baseline; median CPU was 1.925112 versus 1.983917 s. This approximately 3.1% wall difference is modest and may reflect shared-host noise; these are not x86 or official cgroup results. Raw samples are in `transitions-bench.json`. The candidate passed 40 mixed-reference corpora, >1 MiB read-boundary, distributed top-ten, overlap and full 250,000-document / 19,000-duplicate-phrase stress checks. Independent byte-level review passed; target x86 measurement is still needed.

To reproduce the paired full-data comparison, compile both Rust files with identical release flags and run `python3 experiments/b-rust-lengthhash/compare.py --baseline /path/to/base --candidate /path/to/candidate --data /path/to/full-b --runs 7 --report /tmp/b-transitions.json`. No Mac Docker was used.

Independent overflow-checked `property.rs` passed 4,816,896 single-byte/lane cases, all 65,536 ASCII token/separator 16-byte masks and 100,000 random byte vectors against the scalar tokenizer. `rustc --edition=2021 --test -C opt-level=2 -C overflow-checks=yes experiments/b-swar-transitions/property.rs -o /tmp/b-transitions-property && /tmp/b-transitions-property` reproduces the check. This validates the transition/classification logic; it does not measure x86 speed.

Two later paired dot VM x86 passes showed 3.0–6.1% lower wall time for the scanner. Across the B/C campaign all 112 full hashes and 16 alternate references passed, along with scanner stress. Exact samples were not supplied here. These native results warrant official practice but are not cgroup or final scores.
