# Rust B Boolean clause prototype (not selected)

This isolated prototype is based on the merged Rust B at commit `073646e`: baseline source SHA-256 `805b05559c1cf73c14befbaad3f0f7cf0ef94468e64a1192709bbfe7d558ccb1`, candidate SHA-256 `f4039ce8010d33e61505e1cbdc891ed72fc06d3cbc7af8f905e3565d75b31f5d`. It distributes a left-associative Boolean expression into at most six union clauses; AND and NOT constrain every existing clause, OR adds a positive singleton. Each clause chooses its shortest positive posting and tests other membership by binary search. Sorted clause streams merge and deduplicate directly into count, sum and first ten. A conservative cost heuristic falls back to the existing bitmap/postings evaluator; single terms bypass it. Bounded phrase summaries are unchanged. This experiment has not received independent code review and is not selected.

Six randomized full-seed native pairs after a warmup all matched the published hash. On the shared macOS ARM host, median wall was 0.4344 s candidate versus 0.4405 s baseline, median CPU 2.256 versus 2.306 s, and maximum process RSS 528,367,616 versus 540,016,640 bytes. Raw warmup and measured samples are `report.json`. The approximately 1.4% wall difference is too small and noisy to support adoption; process RSS is not cgroup memory, source-size and target x86 measurements are unknown.

For a forced clause-path correctness check, replace the single line `if clause_cost.saturating_mul(3) < bitmap_cost {` with `if true {` in a temporary source copy, build it with `rustc --edition=2021 -C opt-level=1 -C overflow-checks=yes`, and use `B_RUST_BINARY=/path/to/binary` with `experiments/b-rust-positional-adapter.py`. The forced build passed 5,364 expressions over all 64 six-term membership patterns (`experiments/b-boolean-clauses/algebra.py`) and 40 mixed reference corpora (`experiments/b-bounded-fuzz.py`). The ordinary candidate passed the 250,000-document/19,000-duplicate-phrase stress. No Mac Docker was used.

For full-seed timing, compile both sources with identical `rustc --edition=2021 -O -C lto=fat -C codegen-units=1 -C panic=abort`, then run `python3 experiments/b-rust-clauses/compare.py --baseline /path/to/base --candidate /path/to/candidate --data /path/to/full-seed1 --report /tmp/b-rust-clauses.json`. The comparator warms, randomizes each pair, verifies each hash and reports native wall/CPU/RSS. Verify x86 ISA, cold/warm state, source size and actual cgroup memory separately; this script is not an official benchmark.
