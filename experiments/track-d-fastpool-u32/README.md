# D narrow radix pool with 12-byte nodes (unselected)

`baseline.rs` is the exact selected capped-hybrid source SHA-256 `671c639be3400209e83e080dfb54947affd30ca71dc34ec17804d24d70292d9c`. `candidate.rs` is SHA-256 `8c57560c27df2b2acc2fc17238491a2511bc1ce71a5148233f3a14ba8e94f0f4`. The isolated candidate changes only `FastHeap`: its node key and last-key fields become u32, its node layout becomes 12 bytes, and its bucket table has 33 entries. `Search32::reach` inserts only distances strictly below `u32::MAX`; the u64 search and fallback remain unchanged. The candidate uses a checked conversion plus debug assertion and has no new unsafe code. This is experimental and unselected.

The optimized overflow/debug build passed one million randomized monotone heap operations against a BTreeMap model (including reinitialization near the narrow maximum), forced pool exhaustion and cleanup with capacities 0, 1 and 2, 80 independent random directed graphs/16,000 shortest-path queries, 4,096 exhaustive directed graphs/36,864 queries, and cutoff-minus-one, cutoff, cutoff-plus-one, zero, self and unreachable tests. `run-pool-property.py` also asserts a 12-byte pool node layout on the test target. No independent review, actual x86 execution or full-scale cgroup test was performed.

On the official public seed-1 **sample** (not full), two randomized 15-pair native ARM screens after warmups produced candidate/baseline median wall seconds `0.020486/0.019483` and `0.020842/0.019895`; CPU seconds `0.106828/0.101433` and `0.107954/0.102921`. All 64 warmup and measured outputs matched the published sample hash. Maximum native process RSS was approximately 44.8/44.7 MB and 44.7/44.8 MB; this is not parent-cgroup accounting. These short, shared-host timings show a 4.8–5.1% regression, not a target-box or official result. No Docker was run on the Mac.

To reproduce in a suitable native environment, use `python3 run-pool-property.py` and `python3 run-forced.py` from the repository root via their full paths, run the graph oracles under `experiments/track-d-balanced-frontier/`, and invoke `compare.py --data <official-sample-directory> --build-dir <scratch> --report <scratch-report.json> --runs 15`. The sample dataset is generated separately and is not included.
