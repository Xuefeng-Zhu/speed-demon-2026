# First-use hour vector reservation (not selected)

The candidate reserves 4096 packed records when a per-worker hour vector is first used. It changes no parsing or aggregation semantics. Baseline is current selected Track A; both Linux sources are preserved here. For the local macOS screen only, temporary copies changed the anonymous mmap flag from Linux 0x20 to Darwin 0x1000. Seven randomized full seed-1 pairs at 12 workers following warmup all matched the published output hash. On a shared ARM Mac, candidate median wall was 0.050944 s vs baseline 0.049654 s; CPU 0.191630 vs 0.195725 s, maximum process RSS 285,638,656 vs 285,573,120 bytes. See `mac-arm-report.json` for individual samples. Host contention and different target architecture mean these are not official timings or cgroup memory; no wall-time gain was established. This is not selected and has not received broader edge/reference testing.
