# A ordered vectored output (unselected)

`baseline.rs` is the selected Track A source SHA-256 `4af40353f517f566217b0f882ec25d8002f61d211dcc479c53f8a1dd5de7ed88`. `candidate.rs` SHA-256 `3008466af16d6808e53c54b8df5c454f6b7c1b0436d1f3449990d8f7b3c3adad` changes only the output writer: after a finished hour arrives, it batches the maximal contiguous ready prefix with `write_vectored`, preserving hour order and overlapping writing with remaining summaries. A single ready buffer still uses `write_all`. Empty buffers are skipped inside vectored calls, and the writer handles interrupted and partial writes and returns an error on zero progress. At most 72 buffers exist. Nothing was selected or pushed.

`python3 experiments/a-writev-batch/run-tests.py` compiled the exact candidate with debug and overflow checks and passed three independent fake-writer tests. Those cover 160 randomized completion orders over 72 hours, forced one-byte and other short writes, interruptions, empty hours, `WriteZero` and a broken pipe after a partial write. These checks exercise output buffering semantics; Linux-specific `writev` and platform IOV limits have not been independently tested. A process-level error aborts the run rather than attempting to resume partial output.

Two serialized, randomized 15-pair ARM macOS full seed-1 screens after warmup matched all 64 published output hashes. Candidate/baseline median wall seconds were `0.039008/0.039986`, then `0.043376/0.040875`; median CPU seconds `0.190152/0.189338`, then `0.191218/0.189889`. The repeat regressed about 6.1%; there is no stable wall-time or CPU improvement. This is native shared-host ARM evidence, not Linux x86, official scoring, or cgroup memory. Native test copies changed only the Linux anonymous mmap flag for Darwin. Raw samples and compiler identity are in `arm-a.json` and `arm-b.json`.

To reproduce against independently generated full seed-1 data, run `python3 experiments/a-writev-batch/compare.py --data /path/to/full-a --report /tmp/a-writev.json --runs 15 --threads 12`; it hashes every output and reports native process RSS rather than cgroup peak. No datasets, credentials or binaries are included. No Mac Docker was used.
