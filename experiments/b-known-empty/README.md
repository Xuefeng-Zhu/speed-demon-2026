# Track B known-empty Boolean fast path (experimental)

The candidate skips bitmap clearing and operations only while the chunk-local Boolean result is provably empty. An AND with empty postings establishes emptiness; OR with nonempty postings clears the stale bitmap before reviving the result. A true flag means only possibly nonempty. Phrase summaries, tokenizer, exact key comparison and bitmap payload cap remain unchanged. The baseline is selected B at commit `8c273db` (SHA-256 `322cc95ee08cf6d4abc5e1b52240753f66c7eaf89ab669cb6d72b0a8487dc458`); candidate SHA-256 is `8c093a8af4114fef2602563ad55519a29563f5db86f25a1bda96ecd2009dd9bb`. Neither selected source nor board was changed.

Seven measured randomized native Mac ARM pairs after warmup all matched the full seed-1 SHA-256, with medians 0.249121 s candidate versus 0.257911 s baseline and CPU 1.553615 versus 1.585571 s. A 15-pair repeat also matched every hash, with medians 0.255112 versus 0.257820 s and CPU 1.552709 versus 1.576181 s. Shared-host scalar-path results are noisy, not x86 or official scoring. Raw runs are in `report.json` and `repeat.json`.

Independent review found no correctness defect: 310,536 byte-exact reference comparisons covered mixed AND/OR/NOT, empty and revived results, 9 document counts, worker counts 1/2/3/7/12/32, and normal/zero/8-byte bitmap caps, with overflow checks. Run `python3 experiments/b-known-empty/independent-review.py experiments/b-known-empty/candidate.rs official/reference/b_index.py`. The candidate also passed 5,364 Boolean expressions × 64 memberships, 40 mixed references, distributed top-ten/overlap, >1 MiB boundaries, and the full 250k-document/19k-duplicate-phrase stress. It needs target x86 and official cgroup measurement before selection. No Mac Docker was used.
