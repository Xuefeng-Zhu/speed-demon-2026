# Bounded owner-head table — unselected

The baseline is selected salted-owner SHA-256 `0aa4cbccf08b05a59aadbe7eaf23a931e468a95f76463a95100a142e8221bc08`; the candidate is `771f3f781393842f6a4d08be88b5713cd952d654e70ed8194f017198f5b9a9d9`. It replaces the randomized map from prehash to chain head with a process-salted, linear-probed table. Any insertion or growth requiring more than 32 probes migrates the owner table to the original randomized `HashMap`; exact-name collision promotion and bitmap rows are unchanged. The probe limit applies per key: a growth or migration still traverses the table, and the fallback's randomized hashing is probabilistic. Record ownership under identical full name hashes remains concentrated as in baseline.

One 15-pair non-official full seed-1 ARM screen produced median wall 0.10398 s versus 0.09718 s selected and CPU 0.54913 versus 0.51269 s. All 32 full output hashes matched. This noisy single batch suggests a regression, not a target-machine finding; no x86 or official measurement has been made. `arm-report.json` preserves samples. Do not promote on this evidence.

The exact candidate passed 120 independent-reference mixed cases across five worker counts, 357 CRLF/quoted-newline cut comparisons, 20 long-name/forced-fallback references, 20 country/group boundary references, 12 repeated-name and forced-hash-collision references, representability gate arithmetic, and the five existing independent collision tests. Independent source review found no defect; `independent-heads.py` checks 400,000 randomized map operations against `HashMap`, forced outer table promotion, simultaneous inner collision promotion, and 50,000 full-hash-colliding names with overflow checks enabled. `heads-tail.rs` supplies additional direct clustered insert/update and resize checks. Actual Linux AVX2 execution, 4 GiB full parsing, cgroup peak memory and target performance remain unverified.

Reproduce the independent tests by running `python3 experiments/c-owner-bounded-heads/independent-heads.py` and `python3 experiments/c-owner-bounded-heads/independent-collision.py`. The `reference.py` default targets the selected source; specify `--source experiments/c-owner-bounded-heads/candidate.rs` when testing this candidate.
