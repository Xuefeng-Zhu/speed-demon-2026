# C numeric scanner and worker-local cache (not selected)

Baseline is the exact CRLF-synchronized C source at `4f2d688`, SHA-256 `3e181c76981348a96b48470844ee0f8988847d32164ff935a211024861c86ad4`. Both candidates keep exact dictionary semantics and compute all results. No data, credentials or precomputed outputs are included.

`numeric.rs` replaces the generic numeric loop with a digit loop and a fixed two-digit cents suffix. It relies on official section 2.2's exact numeric grammar and terminal delimiters; it is not a general-purpose CSV number parser. It passed the full seed-1 output hash on every comparison run, 24 mixed CSV corpora at each of 1/2/3/7/16 workers (120 byte-for-byte reference comparisons), and an overflow-checked property test of all 10,099,999 allowed cent values from -999.99 through 99,999.99 plus integer delimiters. Nine randomized measured ARM Mac pairs after warmup gave 0.198718 s candidate versus 0.214075 s baseline median wall, and 0.960845 s versus 0.992055 s median CPU. These shared-host measurements are noisy and not an x86 or official score. Exact source SHA-256 `ec839f2e552a8032d21a4e0a8fec50ad5ee6e2e9e9f4524706fb92f3dee05fdb`.

`local-cache.rs` adds a 65,536-entry per-worker direct-mapped cache of exact `(name, group)` pairs to avoid repeat locks, with full byte equality on a cache hit. All full seed-1 hashes matched, but nine measured shared-Mac pairs gave 0.368564 s candidate versus 0.265641 s baseline median wall and 1.345340 s versus 1.066565 s median CPU; peak native process RSS grew from approximately 226 MB to 243 MB. The cache was slower in this screen and is not selected. Exact source SHA-256 `626e0dc19f8c9e457ed48106bbcc2c33d132453d61b4c13e5ccd5a36f1417c55`.

Compile with identical `rustc --edition 2021 -O -C lto=fat -C codegen-units=1` flags, then run `python3 experiments/c-numeric-cache/compare.py --baseline /path/to/base --variant /path/to/candidate --data /path/to/generated-full --runs 9 --report /tmp/c-comparison.json`. Repeat the numeric check with `rustc --edition 2021 -O -C overflow-checks=yes experiments/c-numeric-cache/numeric-property.rs -o /tmp/c-numeric-property && /tmp/c-numeric-property`, and mixed reference comparisons with `python3 experiments/c-rust-independent.py --source experiments/c-numeric-cache/numeric.rs --seeds 24`. Native process RSS is not the warmed-cgroup peak. No Mac Docker was used.
