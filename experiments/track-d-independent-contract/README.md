# Low-degree independent-set contraction (unselected)

`baseline.rs` is the selected positioned-read source. The isolated candidate identifies unpinned vertices with at most three input arcs and three output arcs, excluding self-loops and any vertex for which an incoming and outgoing edge can sum past `u32::MAX`. A local-ID rule chooses an independent subset. It reconstructs each CSR by replacing edges through a removed vertex with all exact two-hop directed shortcuts, dropping nonnegative self-return walks. Pinned query endpoints are never removed. All graph-derived work is in the timed run.

The candidate has not received independent proof, thorough unpinned-vertex randomized graph stress, overflow/boundary analysis, nor target-machine testing. Some oracle suites pin all or most of their small graph's vertices, limiting their contraction coverage. No selection or correctness claim for all allowed graphs is made.

The candidate passed 80 random directed graph cases/16,000 oracle queries, 376 directed chain/cycle fixtures, a maximum-size maximum-weight chain, and 6,000 repeated/unreachable queries. All 12 full-seed warmup/measured hashes matched. Five paired shared ARM runs (`report.json`) measured median candidate 0.29007 s versus baseline 0.27451 s; CPU 1.69997 versus 1.80834 s; maximum native process RSS 673710080 versus 534396928 bytes. On one additional instrumented full-seed run with correct hash, 1,240,032 vertices were eligible, 583,348 were removed, and forward arcs fell from 5,000,000 to 4,347,169. Instrumentation is diagnostic and timing is not target x86 or official cgroup evidence. Slower wall time and increased memory do not support promotion; no Mac Docker was used.
