# Four-inline-edge CSR with duplicated full adjacency (experimental, not selected)

This pre-hugepage experiment duplicates the first four edges per row while retaining full adjacency. It passed 16,000 random oracle queries, 36,864 exhaustive small-graph queries and every full hash. The first seven-pair shared native ARM screen gave median 0.2930 s vs 0.2841 s wall and 1.691 vs 1.844 s CPU, with peak process RSS about 674 vs 535 MB. The 11-pair repeat overlaps other shared-host activity and has inconclusive wall timing; raw samples are retained. It is superseded for investigation by compact overflow-only rows at `../track-d-inline-compact/`, but neither is selected. Neither contains the selected bc902c7 hugepage hint or has a target-machine score. No Mac Docker was used.
