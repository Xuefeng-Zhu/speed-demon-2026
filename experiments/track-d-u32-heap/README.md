# D compact-u32 radix heap with u64 fallback (not selected)

This experimental variant extends `experiments/track-d-u32-fallback/`: an initial exact-below-cutoff bidirectional search stores both tentative distances and radix queue entries as u32, with 33 buckets. It repeats a query using unrestricted u64 Dijkstra whenever the first result is `u32::MAX` or greater, including unreachable cases. For nonnegative weights, every prefix and suffix of a path shorter than the cutoff is also below it. This idea has not received independent review and is not selected. Source hashes and complete runs are in `report.json`.

Both the baseline and candidate matched every published full seed-1 hash across seven randomized measured native Mac ARM pairs and one warmup. Candidate median wall time was 0.449165 s versus 0.381574 s baseline; median CPU was 1.995044 versus 1.864791 s; maximum process RSS was 424,869,888 versus 535,265,280 bytes. The shared host was variable, and native RSS is not cgroup memory. Speed-first policy favors the selected baseline; the apparent memory reduction does not establish an x86 or official gain.

The candidate also matched 80 independent random directed graph fixtures / 16,000 Dijkstra queries and explicit cutoff−1, cutoff, cutoff+1, zero, unreachable and self cases. Reproduce with `python3 experiments/track-d-u32-heap/compare.py --data /path/to/full-d --build-dir /tmp/d-u32heap --report /tmp/d-u32heap.json --runs 7`, followed by `python3 experiments/track-d-u32-heap/oracle.py /tmp/d-u32heap/meeting` and `python3 experiments/track-d-u32-heap/thresholds.py /tmp/d-u32heap/meeting`. Full input must be generated separately. No Docker was used.
