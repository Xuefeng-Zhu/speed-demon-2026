# Independent B bitmap-summary review

The reviewed candidate had SHA-256 `322cc95ee08cf6d4abc5e1b52240753f66c7eaf89ab669cb6d72b0a8487dc458`. It summarizes each Boolean result bitmap by using popcount and six bit-position planes for words with more than eight set bits, and iterates sparse bits directly. It retains the first ten IDs in ascending order. This folder is review evidence, not a selected candidate or a benchmark.

The six masks encode the six bits of each set bit's position: summing their popcounts with weights 1, 2, 4, 8, 16 and 32 yields the sum of within-word positions. The per-word base contributes `count * (first + 64 * word_index)`. Under the documented full scale of 250,000 ascending document IDs, the chunk-local count and base fit `u32`, the total sum fits `u64`, and only in-domain bits can be introduced by the existing postings and left-associative bitmap operations. Empty bitmaps produce zero count/sum and no IDs. Phrase handling is unchanged.

`property.rs` embeds the exact candidate aggregation block extracted from the reviewed SHA above and compares it to scalar bit enumeration with overflow checks. It passed every 16-bit mask shifted to each of the four quarter-word positions, individual/edge masks, and 100,000 deterministic random multiword arrays; initial nonempty output buffers were included to test top-ten offsets. Run `rustc --edition=2021 --test -C opt-level=2 -C overflow-checks=yes experiments/b-bitstats-independent/property.rs -o /tmp/bitstats-property && /tmp/bitstats-property`.

`dense.py` compiles the supplied candidate source with forced 1, 2, 7 and 32 worker counts and overflow checks. It generates 20 corpus sizes from empty through 8,193 documents, with densities around 8/9 bits per word and the 64- and 2,048-document boundaries, plus 165 strict-order Boolean/phrase queries each. All 80 case/worker outputs matched the official reference byte for byte. Run `python3 experiments/b-bitstats-independent/dense.py /path/to/candidate.rs` from the repository root. No Mac Docker or dot VM benchmarks were used. The full application source still needs target x86 performance measurement and official practice before any selection.
