# B raw one- and two-byte direct lookup (unselected)

`baseline.rs` is exact selected source SHA-256 `7d371fe84ce9f0fd9d3c7e6fdf02b6b37e0f1440319c654161b990cf27bb8bf3`; `candidate.rs` is `a2691fb564324be0fd4427adad67561d6374be6a27a3d83674343fd29eaaa727`. The candidate allocates 65,536 u32 slots (256 KiB requested payload) and indexes one- and two-byte ASCII alphanumeric tokens directly by their lowercase-normalized raw bytes. Empty slots retain `u32::MAX`; longer terms use the original exact table. A one-byte zero-padded token cannot collide with a valid nonzero second alphanumeric byte. This differs from the earlier base-37 tiny-token table and adds no precomputed corpus data or answers. Lookup paths are initialized before sample or full parsing. Memory is a requested payload, not an official cgroup measurement.

The independent source review and optimized debug/overflow property tests in `../b-direct-byte2-independent/` cover every 36 one-byte and 1,296 two-byte lowercase token, uppercase variants, present/missing and empty query dictionaries, zero length, longer fallback paths, 65 offsets, forced original short-hash collisions, and native guarded pages at both slice ends. The candidate additionally passed `experiments/b-tiny-direct/fixture.py` against the official reference for all 47,988 one-to-three-byte terms, 90 mixed independent reference corpora, and 40 mixed ASCII/Unicode, Boolean/phrase, collision and duplicate query corpora. These checks ran on native ARM, not target x86 AVX2.

A randomized nine-pair native ARM full seed-1 comparison after one warmup gave candidate/baseline median wall `0.247590/0.236434` s and CPU `1.624444/1.521118` s. Median native process RSS was `526,991,360/521,601,024` bytes; maximum was `533,282,816/527,925,248`. All 20 output hashes matched. The candidate was slower in this single shared-host screen and remains unselected; this does not establish target x86 performance or official cgroup memory. Raw data are in `arm-screen.json`. No datasets, credentials, binaries or precomputed answers are included. No Docker was run on the Mac.

To reproduce on a native environment with a separately verified seed-1 dataset, compile both sources identically with Rust release flags and run `python3 experiments/b-rust-lengthhash/compare.py --baseline /path/to/base --candidate /path/to/candidate --data /path/to/full-b --runs 9 --report /tmp/b-direct-byte2.json`; that comparator validates the public output hash. Additional Linux x86 AVX2 and guarded-page execution would be needed before considering target measurement.
