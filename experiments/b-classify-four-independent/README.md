# Independent B four-block tokenizer checks

The exact isolated candidate `../b-classify-four-current/candidate.rs` has SHA-256 `7ffd820e9cfebdd93c515edc9a721c54328f04a7b470490d953df1bf93fd0142`; its baseline is selected source `7d371fe84ce9f0fd9d3c7e6fdf02b6b37e0f1440319c654161b990cf27bb8bf3`. It is not selected code.

Static review found no concrete defect in the four-block loop. The remaining-length guard keeps all four 32-byte reads within one document, masks are consumed in input order, and `pos` advances by one block in every branch. An open token survives all-ones masks and reaches the original tail loop; branches guard shifts by 32. Queries and per-document token vectors are processed in their original order. This reasoning relies on the original immutable input and exact classifier contract; it is not a proof for every input.

`python3 experiments/b-classify-four-independent/run.py` hashes the exact candidate, appends independent properties to a temporary copy, and uses optimized debug/overflow checks. On native macOS ARM it passed 493,216 exhaustive-mask and randomized documents from `../b-avx-transitions/token-tail.rs`, plus 1,520 explicitly constructed document bodies of 127/128/129/255/256/257 bytes with crossings at 32-byte boundaries, tokens over 32 bytes, UTF-8 high-byte separators, and phrase-token order across boundaries. Another 48 whole-document scans place these lengths and four token patterns immediately against the left or right inaccessible guard page, checking the actual `for_each_doc` loop against the scalar oracle. The test uses the native page size and releases its mapping afterward. No generated data or binaries are retained.

On supported Linux x86-64, `python3 experiments/b-classify-four-independent/run.py --x86-v3` first checks the exposed CPU flags required by x86-64-v3, compiles for that target and asserts the actual AVX2 path ran. That mode has **not** been run here; in particular the new whole-document guard checks have not exercised actual AVX2. x86 benchmark and cgroup measurements remain separate requirements. No Mac Docker was used.
