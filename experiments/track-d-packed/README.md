# Track D packed distances experiment

Experimental only. This version packs the per-direction search epoch and distance into one u64 per node per worker, replacing separate u64 distances and u32 visited epochs. It preserves 53 distance bits, 11 epoch bits, and clears the arrays at epoch wrap. It relies on the official full-scale node bound n = 1,740,512, so n * UINT32_MAX = 7,475,442,116,555,040 < 2^53. A Dijkstra node popped from the priority queue has a simple shortest path of at most n-1 edges; one subsequent relaxation therefore remains within n * UINT32_MAX. Code intended for larger graphs needs a wider distance/epoch representation or fallback.

With rustc release builds on macOS ARM and other work active, one warmup plus five alternating full-data pairs yielded median 2.144253 s current vs 1.714400 s packed; all outputs matched published seed-1 SHA-256 a23dbdf0a3e49cc8901310a9ee1dc6a9a569a85297b6da75c2a7002cb2ed277e. See bench.json for all timings. Three fresh-process RSS measurements (bytes) were 513687552, 513507328, 492011520 current; 356745216, 429555712, 430850048 packed; see rss.json. These are process measurements, not official time/cgroup memory, and are not native x86. No board result is implied.

Independent tests: official full seed 1 hash; 80 random directed graphs, 16,000 queries matched independent Dijkstra; 1,740,512-node chain with maximum-weight edges yielded exact 7,475,437,821,587,745; 6,000 queries, 3,000 entering the search in one worker, crossed the epoch reset. `tests_extremes.py` reproduces the last two cases. To create the single-worker test binary, copy src/main.rs and replace `0..6.min(queries.len())` with `0..1.min(queries.len())`; build both with `cargo build --release --offline` in separate target directories. Do not select this variant before x86 and official-harness checks, and retain the bound and rollover tests.
