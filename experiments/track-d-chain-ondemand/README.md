# On-demand degree-two shortcuts (experimental, not selected)

This candidate classifies non-query degree-two nodes as in `../track-d-chain-shortcut/`, but computes bounded directed core-to-core shortcuts during query relaxation instead of constructing two additional adjacency arrays. Missing directed arcs, paths longer than 16 steps or weights exceeding `u32::MAX` keep the original edge; all query endpoints remain pinned. No graph data is precomputed outside the run. Baseline is exact positioned-read D at `b4f634b`.

Overflow/debug-checked candidate passed 16,000 independent random graph queries, 36,864 exhaustive three-node queries, 376 directed chain/cycle fixtures, the maximum-size maximum-weight chain and 6,000 repeated/unreachable queries. All full seed-1 hashes matched. Nine shared ARM native pairs (`report.json`) measured median 0.43827 s candidate vs 0.30320 s baseline, CPU 2.50997 vs 1.82889 s and maximum native process RSS 548,306,944 vs 534,364,160 B. Runtime recomputation outweighed the saved adjacency-copy work; the candidate is unselected and has not received independent graph-equivalence review. This is not x86 or official cgroup evidence. No Mac Docker was used.
