# Track A output-pipeline profile

`baseline.rs` is exact selected A SHA-256 `16ae5a2e4df27269dbcc2f7b21bb9ad1022081d84e68e5b2c3f5b122a7cb04e2`; `profile-linux.rs` adds only phase timers and stderr output. A temporary Darwin build changed only the Linux MAP_ANON flag. Seven warmed shared native ARM full-seed runs at 12 workers all matched the published output hash. Median elapsed times from process start were parse finished 26.75 ms, endpoint merge finished 27.76 ms, first completed hourly output 33.05 ms, and all output written 40.25 ms. The sum of timed `write_all` calls was 7.92 ms; these calls overlapped summary workers and their sum is not an independent critical-path duration. Instrumentation and host contention perturb timings; this is neither official x86 nor cgroup evidence. All individual samples including the cold warmup are in `report.json`. No Mac Docker was used.
