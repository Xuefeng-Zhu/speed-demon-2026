# A compact endpoint table (not selected)

This isolated experiment compresses each endpoint table entry from a 24-byte `(hash, start, end)` tuple to a 16-byte `(hash, packed start and length)` tuple, storing the start in 56 bits and length in eight. The candidate asserts that the mapped offset is below 2^56 and the endpoint length is at most 125; the published full input dimensions are well inside these limits, but it introduces an extra representation bound and needs fallback or careful review before any consideration. It retains exact endpoint comparison. `baseline.rs` is the selected Track A source at the time of the experiment; `candidate.rs` is the variant. Neither selected source nor the competition branch changed.

Eight randomized full-seed native ARM pairs after one warmup all matched the published SHA-256. Shared-Mac medians were 0.04118 s baseline and 0.04198 s candidate at 12 workers, with the only platform change being a temporary Darwin MAP_ANON flag. These close results do not establish an improvement and may be noisy; no target x86 or cgroup measurements were made. `report.json` contains all timings. No alternate-seed or adversarial checks were run because the screen showed no speed gain. No Mac Docker was used.
