# B packed short-slot hash tags (not selected)

The isolated candidate changes only the ≤8-byte term dictionary. Each four-byte slot packs the low 19-bit term ID with 13 hash-tag bits, so an occupied slot whose tag differs can be skipped without loading the separate full key. Matching tags still require exact 64-bit key equality. ID `0x7ffff` is reserved, ensuring no valid packed slot equals `MISS`; if `keys.len()` exceeds `0x7ffff`, the candidate falls back to the original untagged IDs and lookups. Long-token hashing, parsing, phrase and Boolean semantics and bitmap/phrase memory bounds are unchanged. Baseline SHA-256 `322cc95ee08cf6d4abc5e1b52240753f66c7eaf89ab669cb6d72b0a8487dc458`; candidate `5595d49d4c91ea80263bda194584f9247702d88f0838aef36cf1f16dfa5ece04`.

A read-only simulation of seed-1 queries and first 512 KiB of complete documents, after stripping numeric document IDs, estimated 60,937 occupied-slot key reads in the baseline versus 50,019 after tag checks, approximately 17.9% fewer key reads. This measures lookup filtering, not speed. Eleven randomized warmed full-seed pairs on a shared ARM Mac measured candidate/baseline wall 0.284337/0.284577 s, CPU 1.599395/1.587032 s. Fifteen repeat pairs measured wall 0.445088/0.380811 s and CPU 1.621350/1.636073 s. All 56 full hashes including warmups passed. Wall time was noisy and CPU essentially tied; this is not target x86 or official evidence, and the candidate is not selected. Raw samples are `report.json` and `repeat.json`.

`run-property.py` compiles the exact candidate with overflow checks and validates 100,000 generated present/absent terms and an empty table; a forced-zero-hash run checks 5,000. Separate threshold tests cover 0, 1, 0x7fffe, 0x7ffff and 0x80000 keys, a key with all tag bits set, the no-sentinel-collision invariant, and tagged-to-untagged fallback. Normal and forced-zero-hash builds also passed 40 mixed reference corpora each; the normal candidate passed distributed top ten/overlapping phrases, >1 MiB documents and 250,000-document/19,000 duplicate-phrase stress. ARM tests do not execute x86 AVX2. No Mac Docker was used.
