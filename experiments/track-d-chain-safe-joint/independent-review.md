# Independent review of joint in-place chain shortcuts

Reviewed `meeting.rs` SHA-256 `e0f884cae4aa954c1d0c32c6c408e7914ead8ed92cd94319f9651334e4e8936f` against the official directed nonnegative-weight graph bounds. No concrete graph-equivalence, overflow, ownership or concurrency defect was found.

The link table distinguishes an absent arc from a present `u32::MAX` weight via its mask. It preserves query endpoints, ignores self-loops in undirected degree counts, and records minimum parallel weights independently by direction. Shortcut sums are formed in `u64` from values no larger than `u32::MAX`, and a total above that bound or a chain that has not reached a core after 16 transitions falls back to the original core entry. Immutable link data is computed before either graph is mutated. Forward/backward adjacency rows are split into disjoint mutable slices and only read the immutable link table; empty slices when workers outnumber nodes are handled by `split_at_mut`.

The two transformed edge sets need not be exact reverses when unequal parallel endpoint edges create extra dominated shortcuts. However, every shortcut denotes a real directed original path, so a meeting bound cannot underestimate the original distance. Choose a simple original shortest path and split it at core/pinned vertices. Each segment of at most 17 edges whose minimum directed weight fits `u32` has the same minimum core-to-core shortcut in both transformed directions. If longer or its minimum exceeds `u32`, both directions retain the original entry edges and all interior rows. Thus at least one shortest path has a common representation in the forward graph and reversed backward graph, to which the standard min-frontier crossing proof applies. Self-loops and nonnegative cycles can be removed from a shortest path; query endpoints are pinned, so no desired endpoint disappears.

`independent-shortcuts.py` compiles the exact source with overflow and debug checks and compares transformed bidirectional results with an independently implemented Bellman–Ford oracle. It passed 1,200 mostly-unpinned random sparse directed graphs at worker counts 1/2/7 (1,458 cases performed real rewrites); 1,024 reachable chain/cycle cases at those worker counts (804 rewrites); and 16,384 exhaustive four-node directed chain/multiedge cases with just endpoint pins (8,247 rewrites). Targeted tests include asymmetric parallel weights, missing directions, zeros, exact `u32::MAX`, overflow fallback, 17-edge versus longer fallback, and pinned intermediate endpoints. This is not a formal proof of all legal inputs or a target performance test.
