# C quoted-note fast path (unselected)

`baseline.rs` is the selected exact row-cache source SHA-256 `76b341e2b7e880fe4ceeee220206a63b48cd247bba4448aa7991a7ad825e8dd2`; `candidate.rs` SHA-256 `f80e17a8bbe386970b05e5cee87308114cdddab8b7e73d83e52da18fba7a5140`. For quoted notes without an escaped quote, the candidate scans to the first quote and computes its length directly; escaped or unquoted notes use the original `field` parser from the original position. This is an isolated experiment, not selected code.

The exact candidate passed 24 mixed corpus references at 1, 2, 3, 7, and 16 workers (`python3 experiments/c-fused-owner-rebase/reference.py --source experiments/c-note-fastscan/candidate.rs --seeds 24`), including quoted commas, embedded LFs, doubled quotes and unquoted/quoted empty fields. Two randomized 15-pair full public seed-1 ARM batches, including warmup, matched all 64 hashes. Median baseline/candidate wall was 0.074340/0.074996 s and 0.071855/0.069868 s; CPU 0.435222/0.421446 s and 0.430630/0.418773 s. Raw observations are `arm-report.json` and `arm-repeat.json`. Shared-host native ARM results are small and inconsistent in wall time, not target x86 or cgroup evidence. No isolated protected-page/AVX2 tests or independent review were performed. This experiment does not justify a target trial without stronger evidence.
