# Track D parallel graph parser — experimental

Six scoped workers parse disjoint, line-aligned portions of the in-memory graph text; their edge vectors are concatenated before the existing CSR and shortest-path code runs. The regular text input and line format are the official spec's. The candidate is based on the selected u16 epoch version at local commit f45c4cf. No repository files were changed.

On a shared macOS ARM host, after one warmup per binary, five paired runs on the public full seed-1 data all matched SHA-256 `a23dbdf0a3e49cc8901310a9ee1dc6a9a569a85297b6da75c2a7002cb2ed277e`. Median walls were 2.4344 s selected vs 1.8377 s parallel parser; maximum per-process RSS was 473,071,616 vs 580,255,744 bytes. The time and memory factors alone favor the parser by approximately 1.105× K, before source-size or dependency effects. Other work was active; these are not board times or cgroup measurements. See `bench.json`.

It passed 16,000 randomized queries on 80 directed graphs against the independent Python Dijkstra test in `experiments/d_random_review.py`; eight targeted graph tests in `tests_boundaries.py` cover zero edges and each of five split points at digits, spaces and newlines against an independent oracle. Official sample seed 7 matched the reference SHA-256 `88bf36c94620505d1beafe7cd56a08dc2d261b71f9824d2f764d5ce6e5d7872e`. It built offline from the allowlisted Dockerfile and passed the restricted ARM Linux container full hash with uid 65534, no network, read-only root, 8 GB RAM, 512 pids, and 1 GB tmpfs.

Reproduce: `CARGO_TARGET_DIR=/tmp/d-par-parse-target cargo build --release --offline --manifest-path /tmp/d-par-parse/Cargo.toml`, then `python3 /tmp/d-par-parse/tests_boundaries.py`. That script currently expects the binary at `/tmp/d-par-parse-target/release/traverse`. For broader random tests, run `python3 experiments/d_random_review.py /tmp/d-par-parse-target/release/traverse` from the Speed Demon repo root. Run native x86 comparisons and the official harness, including source-size and cgroup memory, before considering promotion.
