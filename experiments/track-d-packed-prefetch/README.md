# D packed-CSR distance prefetch experiments (unselected)

`baseline.rs` is the exact official-testing packed-adjacency D source, SHA-256 `793d13729fe4dabe2a1ed272fef78e19567456676ed8df52c075bc4ac33ebd05`. `generate.py` creates `control.rs` and four prefetch variants from this baseline. The control uses indexed adjacency access without any hint, to measure loop restructuring separately. `ahead1`, `ahead2`, and `ahead4` hint the distance slot of a subsequent neighbor; `whole` hints every row's neighbor slots before the exact normal relaxation pass. On AArch64 the hint is `prfm pldl1keep`; on x86-64 `_mm_prefetch` with T0; other architectures perform no hint. Each address uses `wrapping_add` on the live per-worker `dist` allocation; input-contract node IDs are within that allocation, and the lookahead remains within the current CSR row. The hints do not replace reads or mutate program state. Compact and wide adjacency modes use the same exact decoding as baseline.

The exact x86 prefetch instruction path has **not been built for Linux or executed**. Neither full data nor target cgroup use was tested. The x86 path needs independent pointer/safety review, actual Linux build, exhaustive/ref/oracle and protected-page stress, plus paired full target timings before any promotion. No data or answers are embedded.

On native macOS ARM, all five variants passed the 80-graph independent Dijkstra oracle (16,000 queries each), the 4,096-graph exhaustive suite (36,864 queries each), and 96 sample-seed hash checks including warmups. `ahead1` and `whole` also passed node-count 2^21 and 2^21+1 boundary fixtures with weights through u32::MAX. These tests exercised AArch64 hints, not x86.

In one 15-round native ARM sample rotation, medians were baseline 0.020189 s, control 0.020225 s, ahead1 0.020415 s, ahead2 0.020263 s, ahead4 0.020484 s and whole 0.020608 s. Another agent compiled and ran short tests during this interval, so **these measurements are contaminated**. The dataset has only 10% of full nodes/edges/queries and sub-22-ms timings are noisy; there is no defensible performance claim, and no variant is selected. Native RSS is not official cgroup memory. Full raw hashes, wait4 CPU/RSS, flags and source hashes are in `sample.json`.

For an independent x86 test, generate seed-1 full data separately and serialize benchmarks. Rebuild via `python3 generate.py`, then run `python3 compare.py --data /path/to/full-d --build-dir /tmp/d-prefetch-packed --report /tmp/d-prefetch-packed.json --runs 15`. The default comparator rotates all six binaries, checks the official full output hash and compiles x86 with `target-cpu=x86-64-v3`. Run `python3 oracle.py <all-binary-paths>` and `python3 exhaustive.py <all-binary-paths>`, plus `boundaries.py` for each variant and independent guard/edge checks; repeat timings and include a same-loop control. No Docker was run on the Mac.
