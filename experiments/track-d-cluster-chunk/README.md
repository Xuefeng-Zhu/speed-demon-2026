# Chunk-claimed parallel cluster relabeling (experimental)

The exact baseline is positioned-read Track D at `b4f634b`. The candidate constructs a runtime-only permutation of all graph vertices by parallel bounded BFS clusters (up to 256 vertices each), converts both directed CSR graphs to that permutation, maps each runtime query endpoint, then uses the same exact bidirectional Dijkstra. Each root index is assigned exactly once through a 256-element `fetch_add` chunk; atomic first claims prevent duplicate vertices. A relaxed load before swap avoids writes for vertices already claimed. All graph and query work is performed in the timed run; no input-derived data is shipped.

Debug/overflow-checked candidate passed 16,000 random graph queries, 36,864 exhaustive three-node queries, 376 directed chain/cycle fixtures, the maximum-size maximum-weight chain and 6,000 repeated/unreachable queries. All 44 full seed-1 output hashes in the timed batches and warmups matched. Independent static review found no concrete atomic publication, unique-claim, mapping, u32-bound or ownership defect under the official graph contract; independent exact-source permutation and worker stress passed; see independent-review.md and independent-review.py.

Nine randomized shared native ARM pairs (`report.json`) measured median 0.22647 s candidate vs 0.26678 s baseline, CPU 1.45938 vs 1.85178 s, peak native RSS 567,443,456 vs 535,609,344 B. An 11-pair repeat (`repeat.json`) measured 0.47632 vs 0.57264 s, CPU 1.53763 vs 1.92444 s, peak native RSS 566,902,784 vs 534,315,008 B; the repeat experienced heavy host contention. These include all preprocessing but are not target x86 or official cgroup results. Candidate remains unselected pending Linux x86 and official evidence. No Mac Docker was used.

## Dot VM x86 comparison

The parent-run shared native x86 VM paired batches measured 0.7% faster then 1.8% slower wall time, with no stable win. The positioned-read baseline remains selected; these are native VM results, not official scoring-box or cgroup metrics.
