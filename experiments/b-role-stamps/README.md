# Track B combined role and document stamp (not selected)

The candidate replaces the per-worker `u32` last-document stamp and separate shared `u8` role lookup with a per-worker `u64` containing both, leaving token IDs, exact phrase comparison, Boolean algebra and bitmap caps unchanged. Baseline is selected B SHA-256 `322cc95ee08cf6d4abc5e1b52240753f66c7eaf89ab669cb6d72b0a8487dc458`. Eleven randomized warmed full-seed pairs on a shared native ARM host all matched the published hash; median candidate/baseline wall was 0.314512/0.306119 s and CPU 1.620567/1.614446 s. Process and code caching, shared load, and the scalar ARM path limit interpretation; this is not official x86 or cgroup data. No speed gain was evident and the candidate remains unselected. Broader reference, forced-collision and x86 AVX2 tests were not run. No Mac Docker was used.
