# Track A in-place summary ranks (not selected)

The isolated candidate moves each hour's chunk vectors into a uniquely claimed mutex-protected bucket. During the first summary pass it maps each local endpoint ID to global rank and replaces the high ID bits of that record in place. The second pass reads the stored rank rather than looking up the mapping again. No unsafe code is added; the packed error and latency bits remain intact. It adds transposition and one mutex per hour. Baseline is exact current no-prefault source SHA-256 `16ae5a2e4df27269dbcc2f7b21bb9ad1022081d84e68e5b2c3f5b122a7cb04e2`, candidate is `50dda3d175463a94677bf16559ecad3e1295de1f0cf6c8e279938e77b8c503b1`. This candidate is not selected or independently reviewed.

Eleven randomized full seed-1 pairs on a shared macOS ARM host at 12 workers gave baseline/candidate median wall 0.0408977/0.0408603 s and CPU 0.194128/0.195312 s. All full hashes passed, including warmups. A Darwin MAP_ANON adaptation also passed independent synthetic cases 0/1k/100k/100k, 14 page-edge/reference fixtures, and a 132,624-group grid at 1/2/6/12/64 workers. These figures are nonofficial native screens and not cgroup or x86 results; there was no measured gain. No Docker was used.
